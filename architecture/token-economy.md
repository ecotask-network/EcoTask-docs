# Token Economy

## ECO Token
- Standard Stellar token (SEP-41 compatible)
- Minted only by reward-engine contract
- Fixed supply cap: 100,000,000 ECO
- Reward curve: diminishing minting rate as supply grows

## Distribution
- 60% — Task rewards (minted over time)
- 20% — Team & contributors (vested 2 years)
- 10% — Ecosystem fund (DAO-governed)
- 10% — Initial liquidity

## Reward Formula
reward = base_rate * difficulty_multiplier * impact_multiplier
- base_rate: ~10 ECO per task
- difficulty_multiplier: 1.0–3.0 based on task complexity
- impact_multiplier: 1.0–5.0 based on environmental impact (trees vs trash)
