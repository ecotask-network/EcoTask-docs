# Contributing to EcoTask Docs

## Prerequisites
- Git
- A Markdown editor (VS Code, Typora, etc.)

## Setup
1. Fork and clone the repository
2. Create a branch: `git checkout -b docs/my-change`
3. Make your changes in Markdown
4. Submit a pull request

## Style Guide
- Use clear, concise language accessible to non-native English speakers
- Include code examples for all API endpoints
- Keep diagrams updated with any architecture changes
- Cross-link between related documents

## What We Need Help With
- Fixing typos, broken links, or outdated information
- Expanding thin sections or adding missing guides
- Translating docs into Swahili, French, Portuguese, or Hindi
- Improving diagrams and architecture visuals
